evidence, verify each factual claim.

PERMITTED SOURCE: Only the provided evidence items and operation results.
OUTPUT FORMAT: Valid JSON only. No markdown, no commentary.

Break the draft answer into individual factual claims and verify each.

Output format:
{
  "claims": [
    {
      "claim": "<single factual statement>",
      "status": "SUPPORTED|DERIVED|CONFLICTING|UNSUPPORTED",
      "supporting_evidence_ids": ["<evidence_id>"],

Rules:
- SUPPORTED: directly backed by source evidence
- DERIVED: result of a deterministic computation on supported data

- Do NOT add facts not in the evidence
- CONFLICTING claims should present the conflict or use a temporal rule
